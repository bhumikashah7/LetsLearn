# LetsLearn

LetsLearn is a curated learning resource designed to guide students through the best **free platforms for skill development, competitive coding, cloud learning, hackathons, and technical portfolio building**.

This repository contains **HTML pages with embedded videos, platform descriptions, step-by-step instructions, and advantages** to help students start learning quickly and effectively.

---

## Purpose

The goal of this project is to help students:

- Discover the best **free learning platforms**
- Build **industry-relevant technical skills**
- Practice **competitive coding and problem solving**
- Participate in **hackathons and technical competitions**
- Build a **strong technical portfolio**

---

## Learning Platforms Covered

### Free Learning & Certification Platforms

- Google Skills Builder  
- Microsoft Learn  
- AWS Skill Builder  
- IBM SkillsBuild  

These platforms provide structured learning paths in **AI, cloud computing, data, cybersecurity, and modern technologies**, along with globally recognized badges and certifications.

---

### Competitive Coding Platforms

- LeetCode  
- Codeforces  
- CodeChef  
- AtCoder  

These platforms help students improve **data structures, algorithms, logic building, and coding speed**, which are essential for technical interviews and placements.
